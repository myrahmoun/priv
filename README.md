# Tracker Lens (working name)

Firefox extension that shows what websites tell trackers about you. Observes only; never blocks. Plans: [docs/](docs/).

## Run

1. Firefox → `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on** → select `src/manifest.json`.
2. Open a store, then click the toolbar button to open the inspector for that tab.

## Commands

| Command | Does |
|---|---|
| `npm start` | Opens Firefox with the extension loaded; reloads on code changes |
| `npm test` | Unit tests (no browser) |
| `npm run test:e2e` | Headless Firefox + extension against a fake local store |
| `npm run lint` | Mozilla's add-on checks |
| `npm run build` | Store-ready zip in `web-ext-artifacts/` |

Click the toolbar button to open the inspector for the current tab.

## Layout

Everything in `src/` ships; nothing outside it does.

| Path | Contents |
|---|---|
| `src/background/` | Browser plumbing: `recorder.js` (captures requests), `main.js` (wiring, data loading, messages) |
| `src/decoders/` | Pure logic, no browser APIs: `companies.js` (identifies the company); per-tracker decoders next |
| `src/inspector/` | Raw view: live list of captured requests, filters, JSON export |
| `src/vendor/privacybadger/` | Copied from Privacy Badger (GPLv3). `known_trackers.json` is generated by `python3 scripts/build_known_trackers.py`. |
| `tests/` | `unit/` (Node), `e2e/` (Selenium + Firefox) |
| `scripts/`, `docs/` | Dev tooling and plans |
| `badger/` | Privacy Badger source, for reference only. Delete before release. |
